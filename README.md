## 📌 Sobre o projeto

O **Análise de Ativos Financeiros** é um sistema desenvolvido como parte do
**Projeto Integrado da São Paulo Tech School**.

A plataforma tem como objetivo transformar dados históricos do mercado
financeiro em informações **organizadas, visuais e fáceis de interpretar**.

O sistema utiliza indicadores de análise técnica, principalmente as
**Médias Móveis de 9, 21, 50 e 200 períodos**, permitindo analisar tendências
de curto, médio e longo prazo.

---

## 🎯 Objetivo

Facilitar a análise do comportamento dos ativos financeiros através de uma
interface centralizada, apresentando:

- 📈 Dados históricos
- 📊 Gráficos
- 📐 Médias móveis
- 🔎 Tendências
- 🔄 Cruzamentos entre médias

## 📈 Médias Móveis

O sistema utiliza quatro médias móveis principais:

| Média | Período | Análise |
| :---: | :---: | :--- |
| **MM9** | 9 | Curto prazo |
| **MM21** | 21 | Curto / Médio prazo |
| **MM50** | 50 | Médio prazo |
| **MM200** | 200 | Longo prazo |

Esses indicadores ajudam a visualizar o comportamento dos preços e possíveis
mudanças de tendência.

---

## 🔄 Golden Cross & Death Cross

### 🟢 Golden Cross

Identificação de um cruzamento de uma média de período menor sobre uma média
de período maior, indicando uma possível mudança para uma tendência de alta.

### 🔴 Death Cross

Identificação de um cruzamento de uma média de período menor abaixo de uma
média de período maior, indicando uma possível mudança para uma tendência de baixa.

> Os cruzamentos são utilizados como indicadores de análise e não representam
> previsão ou garantia de resultados futuros.
